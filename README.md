# Calorix
Cross-platform React Native Expo app for calorie tracking, meal logging, and nutrition insights.

## Features

- Track daily calories
- Monitor protein, carbs, and fat
- Search and log foods
- Add custom foods
- Save favourite meals
- Personalised calorie goal calculator
- Local data storage with AsyncStorage

## Tech Stack

- React Native
- Expo
- React Navigation
- AsyncStorage
- JavaScript

## Getting Started

```bash
git clone https://github.com/HeinPyaeSonePhyo/Calorix.git
cd Calorix
npm install
npx expo start
```
## Run Commands
```bash
npm run android
npm run ios
npm run web
```
